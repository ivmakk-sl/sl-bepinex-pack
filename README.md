# BepInEx Pack for Survival Log

The official BepInEx 6 IL2CPP build for the Steam game Survival Log, unchanged, as one zip that a player extracts into the game folder. This repo holds the recipe (the pin and the scripts), not the binaries.

Work in progress. Install steps come with the first release.

BepInEx is the work of the BepInEx team: https://github.com/BepInEx/BepInEx
