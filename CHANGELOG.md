# Changelog

All notable changes to this pack are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The version is the BepInEx build identifier of the pinned build, which is a valid semantic version (a prerelease of BepInEx 6.0.0). A repack of the same build adds `.2`, `.3`, for example `6.0.0-be.788.2`.

## [Unreleased]

### Added

- An optional file on the Nexus page, `6000.2.7.zip`, for a first start that cannot download the Unity libraries from `unity.bepinex.dev`. Put it into `BepInEx\unity-libs\` without extracting it. The release on GitHub carries the same file as a mirror. The pack zip does not change. Tested on a clean install of Survival Log 1.1.18902 (Steam build 25984240).

## [6.0.0-be.788] - 2026-09-20

### Added

- The official BepInEx `6.0.0-be.788` build for Unity IL2CPP, win-x64, with its original files unchanged. Tested on a clean install of Survival Log 1.0.16756 (Steam build 25366138).
- `BepInEx/NOTICE-BepInExPack.txt` with the credits and the LGPL-2.1 license text.
